# Community plugins for Buzz

Discover community-made plugins for Buzz Desktop. H2S2 Studio maintains this independent catalog. Entries use the categories shown in [Buzz’s plugin settings](https://github.com/block/buzz-app/blob/v1.0.4/src/app/plugin-categories.ts).

[Submit a Buzz plugin](https://github.com/h2s2-studio/buzz-plugins/issues/new?template=submit-plugin.yml)

## Install a plugin

1. In Buzz Desktop, open **Settings → Plugins → Manage plugins → Add**.
2. Paste the plugin’s GitHub repository URL into **Git or GitHub repository**. Fill in the listed **Branch or tag** and **Folder** when supplied.
3. Select **Find → Install plugin** and enable the plugin.

## Get listed

Open a [plugin submission issue](https://github.com/h2s2-studio/buzz-plugins/issues/new?template=submit-plugin.yml). Include the installable repository, what the plugin does, its Buzz category, and any host version or service requirements. Add a screenshot or demo link if you have one.

Catalog maintainers review the issue, check that Buzz can find the built plugin at the supplied ref and folder, and add accepted entries to this README. To request a listing update, comment on the original submission or open a new submission issue with a link to it.
